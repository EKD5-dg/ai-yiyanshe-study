# 「易研社」趣味学易网站 · 设计文档

日期：2026-07-27
状态：已与用户确认

## 1. 项目概述

面向零基础年轻人的风水/易经/周易趣味学习网站。定位轻松有梗、门槛低，采用 Duolingo 式游戏化学习方式。纯前端实现，学习进度保存在浏览器本地，无需注册登录。

- 网站名称：易研社（暂定，可改）
- 目标人群：对国学好奇但零基础的年轻人
- 设备支持：桌面端与移动端并重（响应式）
- 内容立场：文化科普 + 娱乐向，起卦等互动功能附免责声明

## 2. 技术选型

| 项目 | 选择 | 理由 |
|------|------|------|
| 框架 | Vue 3（Composition API） | 组件化适合交互密集场景，模板语法直观易维护 |
| 构建 | Vite | 快速开发与静态打包 |
| 路由 | vue-router（history 模式） | 5 个页面的 SPA 导航 |
| 状态 | Pinia + localStorage 持久化 | 进度/积分/徽章本地保存 |
| 测试 | Vitest | 核心逻辑单元测试 |
| 部署 | 纯静态产物 | 可托管于任意静态服务（GitHub Pages / Vercel 等） |

## 3. 视觉风格

新中式水墨 + 卡通游戏化融合（用户选定 A+C 融合）：

- 底色：宣纸米色（#faf6ed / #f5f0e6）
- 主文字：墨黑（#2b2b2b），辅助文字暖棕灰（#8a7f6a）
- 强调色：朱砂红（#a83232），用于按钮、进度条、火焰连击等
- 卡片：白底圆角 + 微立体底边阴影（游戏化质感）
- 布局：桌面端顶部导航 + 分栏；移动端底部 Tab 导航 + 单列卡片流

## 4. 页面结构（5 页）

### 4.1 首页
- 「每日一卦」大卡片：按日期哈希取卦，全站当天同一卦，点击看白话解读
- 四模块入口卡：学堂（带进度条）、风水、起卦、闯关
- 成就侧栏（移动端合并进页面）：灵蕴值、徽章数、连续学习天数、今日任务

### 4.2 易经学堂（关卡式课程，20 关）
- 第一章「阴阳与五行」4 关：阴阳概念、五行相生、五行相克、五行与生活
- 第二章「认识八卦」8 关：乾、坤、震、巽、坎、离、艮、兑（每卦一关）
- 第三章「六十四卦入门」8 关：卦的构成（上下卦叠加）、读懂卦辞、乾坤两卦精讲、常见卦精选（否/泰、既济/未济等）
- 每关 = 一页趣味图文知识点 + 3 道小测题；全对通关得满额灵蕴值，答错可重试
- 关卡顺序解锁，通关状态在关卡地图上以徽章/亮色显示

### 4.3 风水小知识
- 场景分类：客厅、卧室、书桌、玄关、厨房、办公位
- 每条知识为可翻转卡片：正面「宜/忌」标签 + 一句话结论，背面白话讲传统说法的由来
- 已读卡片自动标记，累计阅读数计入成就

### 4.4 趣味起卦
- 三枚铜钱摇六次动画（正统六爻起卦程序：三背为老阳、三字为老阴等）
- 逐爻从下往上生成本卦，标记变爻并推出变卦
- 结果页：卦象图、卦名、白话卦辞解读、变卦提示
- 页面固定免责声明：「内容仅供传统文化学习与娱乐，不构成任何现实决策建议」

### 4.5 答题闯关
- 每局从题库随机抽 10 题（题库约 100 题，覆盖学堂与风水内容，分易/中/难）
- 规则：每题限时 15 秒；连续答对有连击加分；3 命制，答错扣 1 命，命尽即结算
- 结算页：得分、正确率、获得灵蕴值、新解锁徽章
- 徽章墙：共 24 枚，分学习类（通关进度）、答题类（连击/高分）、坚持类（连续天数）

## 5. 数据设计（静态 JSON，位于 src/data/）

| 文件 | 内容 |
|------|------|
| trigrams.json | 八卦：卦名、符号、自然象征、性格意象、趣味记忆口诀 |
| hexagrams.json | 64 卦全量：序号、卦名、上下卦、Unicode 卦象符、卦辞原文、白话解读、趣味一句话 |
| lessons.json | 20 关课程：章节、标题、图文内容块、3 道小测题（题干/选项/答案/解析） |
| fengshui.json | 风水卡：场景、宜/忌、一句话结论、原理说明 |
| quiz.json | 闯关题库约 100 题：题干、4 选项、答案、难度、解析 |
| badges.json | 24 枚徽章：ID、名称、图标、解锁条件描述 |

## 6. 状态设计（Pinia store，localStorage 持久化）

```
userProgress {
  lingyun: number            // 灵蕴值
  completedLessons: string[] // 已通关关卡 ID
  readFengshui: string[]     // 已读风水卡 ID
  badges: string[]           // 已解锁徽章 ID
  streak: { days, lastDate } // 连续学习天数
  quizBest: { score, combo } // 闯关最佳纪录
}
```

- 写入时机：每次通关/答题/阅读后立即持久化
- 容错：启动时解析 localStorage 失败（损坏/结构不符）则重置为初始状态，页面正常渲染不白屏
- 连续天数：当日首次任意学习行为触发更新；隔天未学则清零

## 7. 核心算法

- 起卦：每爻掷三枚铜钱（随机），3 背=老阳(9)、3 字=老阴(6)、2 背 1 字=少阴(8)、1 背 2 字=少阳(7)；老阳老阴为变爻；六爻自下而上成本卦，变爻取反得变卦
- 每日一卦：`hash(YYYY-MM-DD) % 64` 取卦，保证当天恒定
- 连击积分：基础分 × (1 + 0.1 × 当前连击数)，答错连击清零
- 徽章判定：每次状态变更后跑一遍解锁条件检查，新解锁弹出祝贺动画

## 8. 组件划分

```
src/
├── data/            # 六个 JSON 数据文件
├── stores/          # progress store（含持久化与徽章判定）
├── utils/           # 起卦算法、每日一卦、积分计算（纯函数，可单测）
├── components/      # 通用：卦象图、翻转卡、进度条、徽章、导航
├── views/           # Home / Lessons / Fengshui / Divination / Quiz 五个页面
└── router/
```

- 原则：算法与数据为纯函数/纯数据，不依赖组件；组件只负责渲染与交互

## 9. 错误处理

- localStorage 不可用（隐私模式等）：降级为内存态，功能可用但刷新丢进度
- localStorage 数据损坏：捕获解析异常，重置初始状态
- 路由未匹配：重定向首页
- 数据文件随包打包，无网络请求，无加载失败场景

## 10. 测试方案

- Vitest 单元测试：起卦算法（爻值分布与变卦推导）、每日一卦稳定性、连击积分计算、徽章解锁判定、进度解锁逻辑、localStorage 容错
- 人工验收：构建后浏览器走查 5 个页面（桌面 + 移动视口）
