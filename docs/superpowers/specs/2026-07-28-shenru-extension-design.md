## 2. 模块 A：64 卦百科

### 路由与导航
- 新增路由：`/hexagrams`（列表页 HexagramsView）、`/hexagrams/:id`（详情页 HexagramDetailView，id 为 1-64，非法 id 重定向列表页）
- 顶部导航与移动端 Tabbar 增加「📜 百科」（共 6 项）

### 列表页
- 64 卦网格卡片（symbol + 卦名 + 全名），点击进详情
- 筛选：按上卦/下卦各 8 个下拉（或标签）过滤；输入框按卦名搜索

### 详情页
- 头部：卦象图（HexagramFigure）、symbol、fullName、序号、上下卦说明
- 卦辞区：原文 + 白话（复用 hexagrams.json 的 guaci/plain/fun）
- 象辞区：大象传原文 + 白话（新数据）
- 六爻区：初爻至上爻逐条，爻名（如「初九」「六二」）+ 爻辞原文 + 白话解读；乾卦附「用九」、坤卦附「用六」
- 卦际关系区：错卦、综卦、互卦三张小卡（symbol+卦名，点击跳转），由算法实时计算
- 底部：上一卦/下一卦翻页、免责声明

### 站内联动
- 首页每日一卦卡片加「查看百科 →」链接至对应详情页
- 起卦结果页本卦/变卦卡片加「查看百科 →」链接

### 数据：src/data/yaoci.json（64 条，按数组下标 = id-1）
```
{
  "id": 1,
  "xiang": { "text": "天行健，君子以自强不息。", "plain": "白话…" },
  "yaoci": [ { "name": "初九", "text": "潜龙勿用。", "plain": "白话…" }, …共6条自下而上 ],
  "extra": { "name": "用九", "text": "见群龙无首，吉。", "plain": "白话…" }  // 仅乾坤两卦有
}
```
爻辞原文用通行本；白话为 1-2 句现代解读，口吻与 v1 一致（教育+轻松，不宿命）。

### 算法：src/utils/relations.js（纯函数 + 单测）
- `bitsOf(hexagram)`：由 upper/lower 查 trigrams.lines 拼出六爻 bits（自下而上）
- `cuogua(id)` 错卦：六爻全部阴阳互换后查卦
- `zonggua(id)` 综卦：六爻上下颠倒后查卦（乾坤坎离颐大过中孚小过共 8 卦颠倒后为自身）
- `hugua(id)` 互卦：bits[1..3] 为下卦、bits[2..4] 为上卦查卦
- 复用 divination.js 的 findHexagram

## 4. 模块 C：风水进阶专题（3 个）

FengshuiView 翻卡区下方新增「进阶专题」区块，三张专题卡，点击进入同页专题态（模式同 LessonsView 的两态切换，不加新路由）：

1. **八宅与命卦**：图文科普 + 互动计算器（输入出生年 1920-2025 + 性别 → 命卦 + 东四/西四命 + 四吉方/四凶方表格）
2. **九宫飞星入门**：图文科普（洛书九宫、什么是流年飞星、示意九宫格图）
3. **罗盘与二十四山**：图文科普（罗盘结构、二十四山是什么、现代人怎么看方位）

- 专题为纯阅读内容，不计入翻卡已读数与徽章（保持 v1 积分体系稳定）
- 每个专题页顶部显著提示：仅供传统文化科普与娱乐

### 算法：src/utils/minggua.js（纯函数 + 单测）
- 年份四位数字反复相加至个位得 y；男命 `reduce(11 - y)`，女命 `reduce(y + 4)`（结果再归一位）
- 数字→卦：1坎 2坤 3震 4巽 6乾 7兑 8艮 9离；得 5 时男作坤、女作艮
- 输出：命卦名、东四/西四命、四吉方（生气/天医/延年/伏位）与四凶方名称及方位（内置 8 卦查询表）
- 简化说明（页面注明）：按公历年份计算，未处理立春分界
